# Простое веб-приложение без фреймворков (Bootstrap + http.server)

Учебный проект: набор Bootstrap-прототипов страниц интернет-магазина
и минимальное веб-приложение на встроенном модуле `http.server`,
которое демонстрирует базовые принципы работы веб-сервера без
использования Flask/Django и других фреймворков.

## Структура проекта

```
.
├── server.py              # веб-приложение (http.server)
├── requirements.txt        # внешних зависимостей нет — только stdlib
├── .gitignore
└── templates/
    ├── index.html          # прототип "Главная"
    ├── catalog.html        # прототип "Каталог"
    ├── category.html       # прототип "Категория 1"
    ├── contacts.html       # прототип "Контакты" — отдаётся сервером
    └── style.css           # общие стили для статических прототипов
```

Все страницы верстаются на **Bootstrap 5**, подключенном с удалённого
CDN (`cdnjs.cloudflare.com`) — локальных копий библиотеки в проекте нет.

## Что делает сервер (`server.py`)

- **GET** (любой путь) — читает `templates/contacts.html` через
  контекстный менеджер (`with open(...)`) и отдаёт его с заголовком
  `Content-Type: text/html; charset=utf-8`.
- **POST** — читает тело запроса, парсит форму (`name`, `email`,
  `message`) и печатает полученные данные в консоль сервера.
- **`/favicon.ico`** — отдаётся отдельным ответом `204`, чтобы не
  засорять лог лишними ошибками.
- Ошибки чтения файла или обработки запроса возвращают страницу
  **500** с трассировкой в консоли; несуществующий метод/ресурс может
  быть расширен до отдельной страницы **404** (пример уже заложен в
  коде — метод `_send_404`).

> Важно: страницы `index.html`, `catalog.html`, `category.html` —
> это статические прототипы из задания 1 (открываются напрямую в
> браузере, без сервера). Сервер из задания 2 всегда отдаёт именно
> `contacts.html`, независимо от запрошенного пути — так требует
> формулировка задания.

## Как запустить

Требования: Python 3.9+ (проверено на 3.12), сторонние пакеты не
нужны.

```bash
python server.py
```

После запуска сервер слушает `http://localhost:8000/`.
Откройте адрес в браузере — увидите страницу «Контакты».
Отправьте форму — данные появятся в консоли, где запущен сервер.

Остановить сервер: `Ctrl+C`.
